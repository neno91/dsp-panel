DSP Panel – administration

DSP

DSP connection Extron DMP 128 / DMP 64

State reads go one at a time with the gap between them (increase the gap if the DMP drops the link at start-up; 75 objects are read in about 75 × gap). User actions may be sent in a burst – a group fader moving five zones sends all five gain commands at once (burst 5) instead of one per gap.

Control

Direct: input n → level 401(n−1), mute 400(n−1); zone with output o → 600(o−1). Groups: input n → gain group n / mute group 10+n, zone o → 20+o / 25+o.

Fader ranges dB

Site and panel

With access keys on, the panel, its files, the state and the WebSocket all need a screen's key (GUID): browsers open the link from Screens → Copy link once (kept in a cookie); Crestron screens get it baked in when published. An admin password is then required.

Source groups “Only one at a time”: picking Music 2 switches Music 1 off in the same zone · “Toggle together”: one button per zone for the whole group

Screens and access Crestron screens and browsers/phones – which zones and views each gets, and the key that grants access

Scale magnifies the whole panel on a Crestron screen (1.3 makes the buttons finger-friendly on a 7″ TS-770; 1.0–1.2 on a 10″ TSW-1070). Applied when publishing. A “screen” is also an access: add a row without an IP for browsers/phones and share the link (👁 / Copy link). New key locks out everyone using the old one – publish to the Crestron screen again afterwards.

Publishing uses the saved configuration – save first. The screen only needs network access to the bridge (no Crestron processor). The first publish fetches Crestron's ch5-cli via npm on the bridge host. If direct upload (SFTP to the screen) is not possible, download the .ch5z and load it with Crestron Toolbox.
